# LifeBoost — конструктор зала

Собираете зал для акробатики, акройоги, йоги, растяжки и кроссфита из готовых модулей — от уголка с турником на 4–5 м² до мультизала.
План проверяет зоны безопасности, высоту потолка, покрытие и проход у двери; на выходе — план с марками и размерами,
развёртки стен с отметками крепежа, разрез по высотам и спецификация с закупкой (CSV, SVG, печать в PDF).

Открыть: https://juri-konoplev.pro/LifeBoost/

English: https://juri-konoplev.pro/LifeBoost/?lang=en

Статическая страница без сборки: `index.html`, `css/`, `js/` (обычные скрипты, работает и с диска).
Каталог и цены — `js/catalog.js`, модули и шаблоны залов — `js/modules.js`, правила проверок — `js/checks.js`.
